# Q2. Research and list 3 popular CPU socket types (for example: LGA1151, AM4, LGA1200) and name one compatible CPU model for each.
Ans. Here are three widely used desktop CPU socket types and one compatible processor for each:
| CPU socket  | Example compatible CPU | Manufacturer |
| ----------- | ---------------------- | ------------ |
| **LGA1151** | Intel Core i7-9700     | Intel        |
| **AM4**     | AMD Ryzen 5 5600       | AMD          |
| **LGA1200** | Intel Core i7-10700    | Intel        |
(LGA1151: Used by Intel 8th- and 9th-generation desktop CPUs; the Core i7-9700 is an LGA1151 processor.)
(AM4: The Ryzen 5 5600 officially uses the AM4 socket.)
(LGA1200: Intel's 10th- and 11th-generation desktop CPUs use LGA1200; the Core i7-10700 specifically supports FCLGA1200.)
Important: A matching socket alone doesn't guarantee compatibility. The motherboard's chipset and BIOS support also need to match the CPU. For example, Intel notes that LGA1151 CPUs from different generations can require different chipsets, and LGA1151 and LGA1200 are electrically incompatible.
# Q3. Explain in your own words the primary functions of the CPU and the chipset on a motherboard, and describe how they work together when you open a music app like Spotify.
Ans. > CPU chipset function
>CPU (Central Processing Unit): The CPU is the computer’s main processor. It executes instructions, performs calculations, and makes decisions. It is responsible for running programs and processing the data they use.
>Chipset: The chipset is a group of controllers on the motherboard that helps the CPU communicate with other hardware, such as USB devices, storage drives, networking components, and other peripherals. On modern systems, many functions that were traditionally handled by a separate chipset are built directly into the CPU.
How They Work Together When You Open Spotify>
1.You click the Spotify icon. The operating system sends instructions to the CPU to start the application.
2.The CPU executes Spotify’s instructions. It processes the program’s code and tells the system what tasks need to happen.
3.The chipset and motherboard provide communication pathways. They help transfer data between the CPU and devices such as the SSD, RAM, USB audio devices, and network hardware.
4.Spotify loads its data. The CPU processes information coming from storage and memory, while the relevant hardware controllers handle the movement of that data.
5.Music is streamed. Network hardware receives audio data from the internet, and the CPU helps process the data so it can be played.
6.Audio is produced. The processed audio is sent through the computer’s audio hardware to your speakers or headphones.
>In simple terms: the CPU does the thinking and processing, while the chipset helps coordinate communication between the CPU and many other parts of the computer. Together, they allow an application like Spotify to load, communicate over the internet, process music data, and produce sound.
